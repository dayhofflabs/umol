## Tooling

1. Span reporting and validation

```rust
struct Span {
    start: usize,
    end: usize,
}

struct Spanned<T> {
    value: T,
    span: Span,
}

enum SpannedEdnKind<'a> {
    Nil,
    Bool(bool),
    Int(i64),
    Str(Cow<'a, str>),
    Keyword(EdnKeyword<'a>),
    Vector(Vec<SpannedEdn<'a>>),
    Map(Vec<(SpannedEdn<'a>, SpannedEdn<'a>)>),
    // ...
}

type SpannedEdn<'a> = Spanned<SpannedEdnKind<'a>>;
}
```
