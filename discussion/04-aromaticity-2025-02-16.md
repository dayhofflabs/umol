# Aromaticity

As for aromaticity, I'm really debating the best way of handling it. On one hand, it undermines the ability to apply
valence rules, so it would be preferable to do away with it. But I don't believe it is possible to implement a molecular
graph representation that uses only Kekulé formulas (atoms, single, double, triple bonds) and needs only one graph per
molecule. One compromise that is more principled is to allow for arbitrary n atom pairs - m electron pairs features. But
it is uncharted territory for me, and I am only aware of a recent paper by W.H. Green (MIT) that seems to hint in that
direction.
